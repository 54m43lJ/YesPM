# WebSocket 传输绑定

> [PROTOCOL.md](./PROTOCOL.md) 定义语义层；本文档定义其 WebSocket 绑定。适用：远端（网络）形态的前端。

## 1. 服务

- 命令：`yespm-ws`（独立进程，由后端 Python 包提供）
- 默认监听 `127.0.0.1:8765`（`--host` / `--port` 可调；面向本机/内网部署）

### 启动参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `--host` / `--port` | `127.0.0.1` / `8765` | 监听地址 |
| `--db <path>` | `./yespm.db` | SQLite checkpoint 路径 |
| `--template <path>` | 内置模板 | 模板 YAML 路径 |
| `--config <path>` | `.env` | LLM 等配置 |

## 2. 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/healthz` | GET | HTTP 健康检查 → `{"status": "ok", "version": "0.3.0"}`（供容器/运维探活） |
| `/ws` | WebSocket | JSON-RPC 主通道（UTF-8 JSON 文本帧，一帧一消息） |

## 3. 连接与会话模型

- **一个连接可承载多个会话**：消息内携带 `session_id`，连接本身不绑定会话。
- **事件订阅**：连接创建 / 恢复会话后即订阅该会话事件；同一会话被多个连接订阅（多连接）时事件广播到全部订阅连接。
- **多客户端竞争**：同一会话的输入类请求先到先得（见 [PROTOCOL.md](./PROTOCOL.md) §8）。
- **连接断开不销毁会话**：会话状态在引擎中持续存在（checkpoint 持久化）；重连后 `session/resume` 即可续聊（含挂起中断的补发，见 [PROTOCOL.md](./PROTOCOL.md) 10.3）。

## 4. 认证

不内置认证（仅限本机/内网），全部放行。

## 5. 断线重连（客户端侧）

1. 检测连接关闭（`close` 事件）。
2. 指数退避重连（1s / 2s / 4s，上限 30s）。
3. 重连成功后对**仍活跃的会话**逐个 `session/resume`。
4. 重连期间到达的用户输入由前端暂存，恢复后补发 `input/send`（引擎侧 `queued` 语义兜底，见 [PROTOCOL.md](./PROTOCOL.md) §8）。

## 6. 可选扩展（设计预留）

| 扩展 | 说明 |
|------|------|
| HTTP SSE 只读订阅 | `GET /events?session_id=…` 面向只读观察者（如大屏），无双向能力 |
| CORS 配置 | 启用 HTTP 端点时按需配置；WS 本身不受同源策略限制 |

## 7. 部署形态

```
远端前端 ──WS──▶  yespm-ws (Python)  ── 引擎 + SqliteSaver
                       │
                （后端只提供 API，前端产物由各前端自行分发）
```
- 建议内网部署；如需公网暴露，置于反向代理后并启用认证。
